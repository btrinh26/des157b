Project Overview

My project is an interactive climate change website designed to inform users about the long-term effects of rising global temperatures. The project uses scroll animations and data visualization to do this. The main audience is people who know about climate change and that it is generally bad, but don’t know everything in detail. My goal was to make the content accessible and visually engaging so that users walk away being very well informed about climate change.

Project Research

For my comparative research, I looked at some projects to get a rough idea of how narratives could be formatted and sorted. Originally, I wanted to include tons of data and charts. This is a good way to present information, but it could overwhelm users easily. The research really helped me scale back and refine the way I structured the project. At first, I wasn’t doing a climate project, but as my ideas progressed, I felt confident in the research I did for that subject.

Visual Design

Early drafts had too many charts and information overload, so I simplified the layout after receiving feedback. Visually, I wanted a professional and sleek look, with as little elements as possible. I am presenting a ton of information, so I didn’t want the page to have too much information overload. The font choice is inter, so it is sleek and easy to read. The information is also spaced out and sectioned to be more digestible.

User Interface

I used a vertical scroll structure to create a smooth user experience, with animations triggered by scroll events to emphasize information. For example, as users scroll, a chart with information about temperature anomalies gets highlighted. Navigation is only through scroll, allowing intuitive navigation. I tried to use consistent layouts to help with the cognitive load as well.

Revisions

During user testing, I noticed people got stuck on a few sections where animations didn’t trigger smoothly or text wasn’t clear enough. I adjusted the timing of scroll-based animations and rewrote some copy to be more direct. I also made labels for everything for user experience and removed a lot of charts for cognitive load. One thing I would do if I had more time is expand the interactive features. Sliders and cards can provide a lot of interaction.

Summary

Working on this project taught me a lot about storytelling and showcasing information. I’m most proud of how the final site feels cohesive and engaging. The most challenging part was narrowing the scope, since I had so many ideas with features. This project helped me grow as a designer in HTML and CSS.
